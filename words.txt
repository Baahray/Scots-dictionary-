# English – Scots dictionary (Scots words only, Glasgow flavour)
#
# ONE ENTRY PER LINE:   english | scots | how to say it | note | example
#   - several Scots words go in the second part, separated by commas – the first is the most common
#   - "how to say it" is spelled the way an English reader would sound it, one per Scots word, same order
#   - note (optional): Glasgow, East, NE, Borders, Shetland, old, phrase… If Scots has no word of its own,
#     start the note with "No separate Scots word – this is how it's said"
#   - example (optional): a Scots sentence with the English in brackets, e.g.  Haud yer wheesht! (Be quiet!)
#   - a Scots entry with a space in it (haud yer wheesht) is a phrase and shows in the Phrases tab
#   - lines starting with # are ignored; the app sorts everything itself
#
# Example:   cold | cauld | cawld | | It's cauld oot. (It's cold out.)
#
# Easiest way to change things: tap Edit in the app. Or edit this file on GitHub and commit.
