How to say it

Scots spelling follows how it's said. Learn these sounds and you can read any word in the dictionary out loud.

    The play buttons use your phone's built-in voice. On an iPhone, a Scottish voice gives the best result: Settings → Accessibility → Spoken Content → Voices → English → Fiona (Scotland).

    Turn on editing

    Editing saves your changes straight to the word list on your GitHub. It needs a key from GitHub, made once:

    1. Open GitHub → new access token and sign in.
    2. Name it Scots app. Set an expiry you're happy with.
    3. Under Repository access, choose Only select repositories → Scots-dictionary-.
    4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. Tap Generate token, copy it, and paste it below.

    Enter your password to edit the word list.
